# Ends and Coends

For a tensor with two occurrences of the same finite index, `coend` extracts the diagonal and
reduces it with the `Algebra`'s join, and `end` reduces it with the meet. In the general
construction, an [end or coend](https://ncatlab.org/nlab/show/end) must also satisfy compatibility
equations for the morphisms of the indexing category [@kelly1982basic]. [Ends and coends](../../guides/enriched.md#ends-and-coends) states the
[scope of the finite implementation](../../guides/enriched.md#ends-and-coends).
