# Weighted Limits

A weighted limit describes compatible ways of mapping into a diagram of objects; its
weight specifies the contributions required from the diagram. The routines below form
finite tensors using the selected algebra and internal-hom operations. Their
relationship to the general universal property depends on the diagram and weight, as
explained in the guide.

See [the scope of the weighted limit operations](../../guides/enriched.md#weighted-limits) and
[the weighted relations used by these constructions](../../semantics/setting.md#2-v-enriched-relations).

For the general enriched constructions behind this finite interface, see [@kelly1982basic].
