# Weighted Limits

A weighted limit describes compatible ways of mapping into a diagram of objects; its
weight specifies the contributions required from the diagram [@kelly1982basic]. The routines below form
finite tensors using the selected algebra and internal-hom operations. Their
[relationship to the general universal property](../../guides/enriched.md#weighted-limits) depends on the diagram and weight, as
explained in the guide.
