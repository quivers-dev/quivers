# Categories

Here “category” means a grammatical type, such as a noun phrase or a function needing a
noun phrase to form a sentence. Slash and product types specify how constituents can
combine. This use of the word is distinct from a mathematical category of objects and
morphisms, though the guide relates the two.

See [types for left and right argument requirements](../../semantics/schemas.md#3-residuated-type-formers) and
[a parser built from schemas](../../examples/schema-chart-parser.md).

For categorial grammar and type-directed combination, see [@lambek1958mathematics].

Category types for categorial grammars: atomic, slash, product, unit,
and modal categories, plus the finite `CategorySystem` used by chart
parsers.

The category types form the free algebra generated by atoms and type
constructors. `CategorySystem.from_generators()` enumerates this
algebra to a specified depth, producing finite category inventories for
CCG, Lambek, multimodal TLG, and custom rule systems.

For grammatical categories and modal type constructors, see [@lambek1958mathematics; @moortgat1997categorial].
