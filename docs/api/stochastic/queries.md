# Queries

Queries compute [expectations, marginals, and related summaries](../../guides/stochastic.md#queries-probability-and-expectation) from distributions or
transition tables. A marginal sums over the variables being removed; an expectation
weights possible values by their probabilities [@bishop2006pattern]. Identify the fixed input and the
variables being reduced when choosing a query.
