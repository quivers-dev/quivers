# Families

A finite distribution family assigns probability weights to finitely many outputs. Its
parameters control how that mass is distributed. When a family discretizes a continuous
density, inspect its construction: normalizing values at bin centers and integrating
probability over bins are different approximations.

See [finite distribution families](../../guides/stochastic.md#discretized-distribution-families) and
[a Markov kernel calculation](../../tutorials/python/02-stochastic-relations.md#composition-of-markov-kernels).
