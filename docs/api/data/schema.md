# `quivers.data.schema`

A [dataset schema](../../guides/analysis-data-and-formulas.md#dataframes-quiversdata) records the meaning and organization of encoded columns, including
their roles in model inputs and observations. It provides a common description for
constructing QVR declarations and packing data. Use it to keep the model’s finite index
sets aligned with the [category codes in the supplied table](../../guides/inference-foundations.md#host-data-per-row-covariates-and-index-arrays).

`DatasetSchema` and the `compose` helper.
