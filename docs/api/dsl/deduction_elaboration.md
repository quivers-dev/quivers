# Deduction elaboration

A deduction declaration names rules and how their results combine. Elaboration
represents that behavior through explicit core families, handlers, and computations.
This is the bridge between a compact rule declaration and the structures that the
checked execution path can inspect.

See [the computations generated by a deduction](../../reference/qvr/generated-computations.md#deduction-declarations) and
[inspecting generated effects](../../tutorials/qvr/11-parsing-and-search.md#3-see-the-generated-effects).

Elaboration of `deduction` declarations into QIEC families, handlers, and
computations.
