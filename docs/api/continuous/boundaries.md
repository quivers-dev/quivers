# Boundaries

`Discretize` and `Embed` move between bounded continuous spaces and finite sets
([the boundary](../../guides/continuous-spaces.md#discrete-continuous-boundary)). `Discretize`
represents a continuous value by one of finitely many bins, and `Embed` assigns a continuous value
to each element of a finite set. The bins and representatives chosen determine how well the result
approximates the original distribution.
