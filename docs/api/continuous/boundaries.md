# Boundaries

Discretization represents a continuous space by finitely many bins or representatives.
Embedding assigns continuous values or distributions to finite indices. Inspect the
selected representatives and weights when choosing either operation: they determine the
approximation to the original distribution.

See [embedding and discretization](../../guides/continuous-spaces.md#discrete-continuous-boundary) and
[the distinction between mass, density, and a sampled value](../../getting-started/concepts.md#5-a-distribution-is-more-than-one-sample).

and finite sets.
