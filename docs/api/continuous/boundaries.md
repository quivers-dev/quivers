# Boundaries

[Discretization](../../guides/continuous-spaces.md#discrete-continuous-boundary) represents a continuous space by finitely many bins or representatives.
Embedding assigns continuous values or distributions to finite indices. Inspect the
selected representatives and weights when choosing either operation: they determine the
[approximation to the original distribution](../../getting-started/concepts.md#5-a-distribution-is-more-than-one-sample).

`Discretize` and `Embed`, which move between bounded continuous spaces
and finite sets.
