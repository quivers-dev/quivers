# Program

The top-level `Program` contains named objects, morphisms, and exports compiled from a
module. Use its lookup methods to select the particular model or other exported
computation you want to execute, then pass that computation to an execution or inference
procedure.

See [loading a module](dsl/index.md#quivers.dsl.load) and [inspecting its declarations](../tutorials/python/09-debugging.md#inspecting-a-compiled-program).
