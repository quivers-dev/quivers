# Plate-graph renderers

These renderers display the sites, repeated dimensions, and dependencies in a program’s
plate graph. Use the diagram to inspect which draws repeat over observations and which
parameters are shared across them.

See [displaying a program's structure](../../guides/repl-and-lsp.md#program-exploration) and
[the repeated draws shown in a plate graph](../../guides/dsl-programs-and-lets.md#indexed-bind-plate).
