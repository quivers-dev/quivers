# Plate-graph renderers

These renderers display the sites, repeated dimensions, and dependencies in a program’s
[plate graph](../../guides/repl-and-lsp.md#program-exploration). Use the diagram to [inspect which draws repeat](../../guides/dsl-programs-and-lets.md#indexed-bind-plate) over observations and which
parameters are shared across them.
