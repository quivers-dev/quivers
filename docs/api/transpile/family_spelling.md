# Family spelling

`spell_distribution` writes a QIEC distribution construction in a dynamic target's own
[distribution constructors](../../semantics/transpile-architecture.md#7-adding-a-new-family) and
expression syntax, for a family and parameters already identified. A correct spelling is one part
of a correct translation, and the support, normalization, and parameter conventions must also
[agree](../../semantics/transpile-correctness/index.md#2-correctness-criterion).
