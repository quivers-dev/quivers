# Family spelling

Each target has its own [distribution constructors](../../semantics/transpile-architecture.md#7-adding-a-new-family) and expression syntax. These helpers
translate an already identified family and its parameters into that spelling. Correct
spelling is one part of correctness; [support, normalization, and parameter conventions
must also agree](../../semantics/transpile-correctness/index.md#2-correctness-criterion).
