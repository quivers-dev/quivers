# Traced Monoidal

A categorical trace connects an output component to a matching input component [@maclane1998categories]. For
finite tensors, this amounts to [identifying the two axes and reducing the resulting
diagonal](../../guides/categorical.md#traced-monoidal-structure). Use the stated contraction rule to determine which values combine and which
axes remain.

Cartesian and iterative traced monoidal structures, with `trace` and
`partial_trace` operations.
