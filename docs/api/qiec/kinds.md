# Kinds

A kind says what sort of static argument is expected, such as a type or an index. A
telescope is an ordered parameter list in which later parameters may depend on earlier
ones. For a length-indexed vector, these distinctions keep the element type and length
separate from its runtime elements.

See [kinds and ordered static parameters](../../reference/qvr/types-and-indexed-families.md#kinds-and-binders) and
[using a vector length index in a fold](../../tutorials/qvr/09-indexed-data.md#2-fold-without-a-shape-check).
