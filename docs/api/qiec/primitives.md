# Primitives

Pure primitives are the core’s basic computations on values. The registry records their
names, types, and implementations. Adding an operation requires a representation that
the checker accepts and an implementation on each runtime where it will execute.

See [the core's built-in operations](../../reference/qvr/computations.md#built-in-values-and-distributions) and
[the typing of computations and their effects](../../semantics/typing.md#6-computations-and-rows).

The closed registry of pure primitives values may apply.
