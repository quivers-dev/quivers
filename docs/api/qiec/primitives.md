# Primitives

[Pure primitives](../../reference/qvr/computations.md#built-in-values-and-distributions) are the core’s basic computations on values. The registry records their
names, types, and implementations. Adding an operation requires a representation that
the [checker accepts](../../semantics/typing.md#6-computations-and-rows) and an implementation on each runtime where it will execute.

The closed registry of pure primitives values may apply.
