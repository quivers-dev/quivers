# Types

Static terms represent types, shapes, and indices. A vector’s length index, for
instance, constrains how many elements a value contains. The checker tracks that
constraint through constructor applications and effectful computations.

See [types indexed by shapes or values](../../reference/qvr/types-and-indexed-families.md#family-declarations) and
[using a vector length index in a fold](../../tutorials/qvr/09-indexed-data.md#2-fold-without-a-shape-check).
