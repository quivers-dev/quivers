# Types

Static terms represent [types, shapes, and indices](../../reference/qvr/types-and-indexed-families.md#family-declarations). A [vector’s length index](../../tutorials/qvr/09-indexed-data.md#2-fold-without-a-shape-check), for
instance, constrains how many elements a value contains. The checker tracks that
constraint through constructor applications and effectful computations.

Static terms: types, indices, shapes, effect references, and their rendering.
