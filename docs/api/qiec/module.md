# Module

A module groups declarations, definitions, and entry information for checking and
serialization. Run the checker before executing its computations, and provide the
runtime services required by the chosen entry.

See [checking a module before execution](../../reference/qvr/execution-and-tooling.md#check-before-you-run) and
[inspecting an entry signature](../../tutorials/qvr/13-release-workflow.md#2-inspect-the-public-boundary).

Serializable whole-module containers.
