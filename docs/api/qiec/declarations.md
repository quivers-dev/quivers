# Declarations

A [family declaration](../../reference/qvr/types-and-indexed-families.md#family-declarations) describes a collection of types, and its constructors describe how
values can be formed. A [vector family](../../tutorials/qvr/09-indexed-data.md#2-fold-without-a-shape-check) may be indexed by element type and length.
Constructor declarations record which indices and fields result from each construction
so checking can recover those facts when values are matched.
