# Declarations

A family declaration describes a collection of types, and its constructors describe how
values can be formed. A vector family may be indexed by element type and length.
Constructor declarations record which indices and fields result from each construction
so checking can recover those facts when values are matched.

See [declaring an indexed family](../../reference/qvr/types-and-indexed-families.md#family-declarations) and
[using a vector length index in a fold](../../tutorials/qvr/09-indexed-data.md#2-fold-without-a-shape-check).
