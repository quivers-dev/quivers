# Evidence

Equality evidence records an equality established during checking. [Matching a
constructor](../../reference/qvr/types-and-indexed-families.md#indexed-case-analysis) can determine an [index value](../../tutorials/qvr/09-indexed-data.md#2-fold-without-a-shape-check); later checks use that equality to justify a
type conversion. The evidence carries this refinement through the computation.
