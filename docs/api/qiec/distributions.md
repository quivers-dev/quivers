# Distributions

These distributions implement [sampling and scoring](../../reference/qvr/probabilistic-programs.md#fixed-and-conditional-families) for the reference evaluator. The
evaluator and a transpilation target may support [different families or
parameterizations](../../semantics/transpile-correctness/index.md#4-distribution-parameterization); check the target’s support table before translating a model.
