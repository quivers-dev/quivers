# Distributions

These distributions implement sampling and scoring for the reference evaluator. The
evaluator and a transpilation target may support different families or
parameterizations; check the target’s support table before translating a model.

See [distribution calls and their parameters](../../reference/qvr/probabilistic-programs.md#fixed-and-conditional-families) and
[preserving a distribution's parameterization across runtimes](../../semantics/transpile-correctness/index.md#4-distribution-parameterization).
