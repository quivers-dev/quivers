# Programs

A `ProgramEntry` records how an elaborated computation is exposed as a program: the roles of its
parameters, its sites, and its return names
([program declaration](../../reference/qvr/probabilistic-programs.md#program-declaration)), so a caller
need not reconstruct them from source
([public boundary](../../tutorials/qvr/13-release-workflow.md#2-inspect-the-public-boundary)). The
body itself is the checked computation.
