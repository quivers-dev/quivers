# Programs

Program metadata records how an elaborated computation is exposed as a model entry. It
helps callers identify the expected inputs, results, and program-specific information
without reconstructing them from source text. The executable body still lives in the
checked computation representation.

See [the inputs and result of a program declaration](../../reference/qvr/probabilistic-programs.md#program-declaration) and
[inspecting the exported entry signature](../../tutorials/qvr/13-release-workflow.md#2-inspect-the-public-boundary).
