# Programs

Program metadata records how an elaborated computation is exposed as a [model entry](../../tutorials/qvr/13-release-workflow.md#2-inspect-the-public-boundary). It
helps callers identify the [expected inputs, results, and program-specific information](../../reference/qvr/probabilistic-programs.md#program-declaration)
without reconstructing them from source text. The executable body still lives in the
checked computation representation.

Typed entry-point metadata for programs elaborated into computations.
