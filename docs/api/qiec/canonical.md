# Canonical types

These constructors give the [shared core types](../../reference/qvr/types-and-indexed-families.md#kinds-and-binders)
of [QIEC](index.md) one representation, which the checker, the prelude, and the compiler all use, so
that each recognizes the same type whatever its source spelling. They build type descriptions,
not model values.
