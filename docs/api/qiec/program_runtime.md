# Program runtime

This adapter executes program entries on the reference machine and returns the values
and scores callers need. It connects the checked computation to the program interface
used by forward execution and inference algorithms.

See [running and scoring a program](../../reference/qvr/probabilistic-programs.md#running-and-scoring) and
[invoking the program with data and site values](../../reference/qvr/execution-and-tooling.md#run-an-entry).
