# Program runtime

This adapter [executes program entries](../../reference/qvr/execution-and-tooling.md#run-an-entry) on the reference machine and [returns the values
and scores](../../reference/qvr/probabilistic-programs.md#running-and-scoring) callers need. It connects the checked computation to the program interface
used by forward execution and inference algorithms.
