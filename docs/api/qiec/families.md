# Families

The family registry describes a distribution family and its required arguments. Each
runtime or transpiler provides implementations for the parameterizations and event
shapes it supports. Consult the target’s support information when translating a model
that uses one of these families.

See [the source family interface](../../reference/qvr/probabilistic-programs.md#fixed-and-conditional-families) and
[preserving a distribution's parameterization across runtimes](../../semantics/transpile-correctness/index.md#4-distribution-parameterization).
