# Reference support

These helpers implement shared numerical operations for reference distributions,
including parameter validation and conversion. Inspect them when investigating a
discrepancy in a family’s sampling or density calculation.

See [distribution parameter conventions](../../reference/qvr/probabilistic-programs.md#fixed-and-conditional-families) and
[preserving a distribution's parameterization across runtimes](../../semantics/transpile-correctness/index.md#4-distribution-parameterization).
